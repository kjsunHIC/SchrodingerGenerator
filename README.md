# Schrödinger Generator

**Schrödinger Generator (SG)** is a computational framework for **high-dimensional sampling and Monte Carlo integration**. It combines adaptive importance sampling with normalizing flows to efficiently sample complicated, strongly correlated high-dimensional distributions.

The framework is designed particularly for applications involving **many-body quantum systems and high-dimensional phase-space integrals**.

> **Status:** Research code under active development.

---

## Overview

High-dimensional Monte Carlo integration becomes increasingly inefficient when the target integrand is strongly peaked or contains complicated correlations. Schrödinger Generator addresses this problem by combining:

* **Adaptive importance sampling (AIS/VEGAS)** to identify important regions of the integration domain.
* **Normalizing flows** to learn nontrivial correlations in the target distribution.
* **Hybrid/Importance resampling** to obtain efficient samples from the resulting proposal distribution.

The basic workflow is

```text
                 Target integrand
                        │
                        ▼
             Adaptive importance sampling
                        │
                ┌───────┴───────┐
                │               │
          Adaptive grid     Training samples
                                │
                                ▼
                       Normalizing flow
                                │
                                ▼
                         Flow refinement
                                │
                                ▼
                       Combined proposal
                                │
                                ▼
                       SG hybrid sampler
                                │
                         ┌──────┴──────┐
                         │             │
                       Samples     Integration
```

---

## Key Features

* GPU-accelerated Monte Carlo sampling using **PyTorch**.
* Double-precision computation.
* Adaptive importance sampling based on an optimized multidimensional grid.
* Normalizing-flow-based proposal distributions.
* Sequential training of multiple flow transformations.
* Combination of adaptive sampling and normalizing flows.
* Importance sampling with explicit Jacobian factors.
* Systematic and other resampling methods.
* Batch-based computation for large-scale GPU calculations.
* Support for high-dimensional many-body and cluster configurations.
* Diagnostic and visualization tools for sampling and training.

## Method

### Adaptive importance sampling

The first stage uses an adaptive importance-sampling grid to identify regions where the integrand contributes most strongly.

The main integration routine is

```python
I, Ierr, I_MC, grid_ais = SG_AIS_integrator(
    fun_integrand,
    Nd,
    gdv,
    Nsample,
    Nstep,
    param_ais,
    device=device,
    batch_size=batch_size,
    seed=seed,
    stratified=False
)
```

where:

* `Nd` is the dimensionality,
* `gdv` specifies the number of grid divisions,
* `Nsample` is the number of Monte Carlo samples,
* `Nstep` is the number of adaptive iterations,
* `grid_ais` is the optimized adaptive grid.

The routine returns an estimate of the integral together with its statistical uncertainty.

---

### Normalizing flows

Samples generated using the adaptive grid are subsequently used to train a normalizing flow.

The flow architecture is controlled by parameters such as:

```text
--flows
--num-bins
--hidden-dim
--iterations
--batch
```

The current implementation uses spline-based normalizing flows and allows multiple flow transformations to be composed.

A representative construction is

```python
model = create_flow_from_args(...)
```

followed by

```python
trained_model, loss_hist = train_flow(...)
```

---

### Sequential flow refinement

SG can train flows sequentially.

The samples generated by the first trained flow can be transformed and used to train a second flow:

```python
x_train_B, _, _ = trained_modelA(x_train)
```

The resulting transformations can then be combined:

```python
trained_combine = CombinedFlow(
    trained_modelA,
    trained_modelB
)
```

This provides a flexible way of progressively refining the learned proposal distribution.

---

## Hybrid SG Sampling

The final proposal combines the adaptive-grid and normalizing-flow samplers.

A representative call is:

```python
x_SG, x_ais, x_nf, w_SG, f_nf, J_nf, J_ais, idx, status = SG_sampler(
    gdv,
    grid_ais,
    fun_integrand,
    param_ais,
    trained_combine,
    device=device,
    n_vegas_proposals=2000000,
    n_nf_proposals=2000000,
    n_final=10000,
    batch_proposal=20000,
    resample_method="systematic",
    jitter=0.0,
    ess_threshold=None
)
```

The hybrid sampler allows the strengths of the two proposal mechanisms to be combined:

* the adaptive grid provides robust global exploration;
* the normalizing flow captures complicated correlations;
* importance weights correct the proposal to reproduce the target distribution.

## Supported Dimensions

The main driver contains parameter settings for several dimensionalities:

```text
Nd = 2
Nd = 3
Nd = 6
Nd = 9
Nd = 12
```

Different dimensionalities use different target integrands and sampling parameters.

For example:

```python
Nd = 2
```

selects a two-dimensional test problem, while higher-dimensional calculations use the cluster integrand.

The default parameters should be regarded as starting points rather than universal optimal settings.

## Performance

High-dimensional calculations can require substantial GPU memory and computational time.

### Batch size

If GPU memory is insufficient, reduce:

```python
batch_size
```

and/or

```python
batch_proposal
```

before reducing the total number of samples.

### Number of proposals

The hybrid sampler can use millions of proposals:

```python
n_vegas_proposals
n_nf_proposals
```

Increasing these values generally improves statistics but increases computational cost.

### Dimensionality

The computational cost grows rapidly with dimensionality. Parameters suitable for `Nd=2` should not be assumed to be optimal for `Nd=18`, `Nd=36`, or `Nd=60`.

## Scientific Applications

Schrödinger Generator is intended for high-dimensional integration and sampling problems where conventional Monte Carlo methods become inefficient.

Potential applications include:

* many-body quantum systems,
* high-dimensional phase-space integration,
* few- and many-body wave functions,
* nuclear-physics calculations,
* variational and statistical sampling,
* correlated probability distributions,
* high-dimensional Bayesian or statistical integrals.
